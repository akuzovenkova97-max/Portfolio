How I design learning

Whatever the topic, I follow the same steps.

  1. AnalyseI find out what learners need, what they want to achieve and where the gaps are. If the topic is new to me, I work closely with experts.
  2. Set objectivesI set clear, measurable objectives that tie back to the main goal of the learning product.
  3. Plan assessmentI decide early on how to check results, so assessment helps people learn instead of being a box to tick.
  4. SequenceI order the content from simple to complex, with support and practice along the way.
  5. BuildI create the activities and assessments in authoring tools, using AI to speed up drafts and prototypes.
  6. Test and improveI test each course and make improvements wherever results or feedback show they're needed.
